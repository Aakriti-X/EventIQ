# EventIQ

EventIQ is a Python-based Data Science and Machine Learning web application for college event analytics and student attendance prediction.

## Live Demo

[🚀 Open EventIQ](https://eventiq-ml.streamlit.app/)

## Features

- College event analytics
- Data cleaning and exploratory data analysis
- Interactive visualizations
- Student attendance prediction
- Machine learning model performance analysis
- Project management dashboard
- Risk management
- Resource management
- Gantt Chart
- PERT and CPM analysis

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit
- Joblib
